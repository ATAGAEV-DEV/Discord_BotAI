# Команды Discord-бота

Бот использует prefix-команды. По умолчанию префикс — `!`; если в конфигурации задан другой префикс, замените `!` в примерах на него.

В документе описаны 26 зарегистрированных prefix-команд. Slash-команды в текущей версии не зарегистрированы.

## Общие команды

### `!help`

Показывает встроенную справку по основным командам бота.

### `!rank [list]`

Показывает карточку ранга и статистику автора команды.

- `!rank` — показать свой текущий ранг и количество сообщений.
- `!rank list` — показать список всех доступных рангов.

Ограничение: не чаще одного вызова в 10 секунд для одного пользователя.

## Прожарка чата

### `!toxic [количество] [режим]`

Прожаривает последние сообщения текущего чата с помощью AI.

- без аргументов используется 20 сообщений;
- `количество` — число сообщений от 1 до 80; значение автоматически ограничивается этим диапазоном;
- `режим` — дополнительный стиль ответа;
- `!toxic list` — показать доступные режимы.

Примеры:

```text
!toxic
!toxic 20
!toxic babka
!toxic 50 babka
!toxic list
```

Доступные режимы: `babka`, `gopnik`, `teacher`, `conspirolog`, `comic`, `gamer`, `philosoph`, `tsundere`.

Ограничение: не чаще одного вызова в 30 секунд для одного пользователя.

## Описания пользователей

Команды работают в пределах текущего Discord-сервера. `desc_list` доступна всем участникам, остальные команды — только администраторам сервера или назначенным администраторам бота.

### `!desc_add <ник> <описание>`

Добавляет или обновляет описание пользователя.

```text
!desc_add atagaev Арби, создатель бота
```

### `!desc_remove <ник>`

Удаляет описание пользователя.

```text
!desc_remove atagaev
```

### `!desc_list`

Показывает все сохранённые описания пользователей текущего сервера.

### `!desc_reload`

Перезагружает кэш описаний пользователей из базы данных.

### `!emoji_add <имя> <описание>`

Добавляет или обновляет описание эмодзи сервера.


### `!emoji_remove <имя>`

### `!emoji_list`

## Администрирование

Все команды этого раздела работают только на сервере и требуют одного из вариантов доступа:

- право Discord `Administrator`;
- пользователь уже назначен администратором бота на этом сервере через `!admin_add`.

### `!admin_add <имя> <user_id>`

Назначает пользователя администратором бота для текущего сервера. Это не меняет роли и права пользователя в Discord.

```text
!admin_add Alice 123456789012345678
```

`user_id` — Discord ID пользователя, а `имя` — подпись, которая будет показана в списке администраторов бота.

### `!admin_remove <user_id>`

Удаляет пользователя из списка администраторов бота текущего сервера.

### `!admin_list`

Показывает назначенных администраторов бота, их подписи и Discord ID.

### `!reset`

Очищает сохранённую историю сообщений сервера в индексе AI и сбрасывает краткосрочную историю каналов. Служебный документ со списком пользователей сервера сохраняется.

### `!update_user`

Обновляет список пользователей сервера, используемый AI-контекстом. В список попадают участники, не являющиеся ботами.

## YouTube-уведомления

Команды работают только на сервере и доступны администраторам Discord или назначенным администраторам бота.

### `!add_youtube <youtube_id> <discord_channel_id> <название>`

Добавляет YouTube-канал для отслеживания и указывает Discord-канал, куда бот будет отправлять уведомления.

```text
!add_youtube UCxxxxxxxxxxxxxxxxxxxx 123456789012345678 My Channel
```

`discord_channel_id` — ID Discord-канала. Название используется затем в командах `!youtube` и должно совпадать с указанным при добавлении.

### `!youtube <on|off> <название>`

Включает или отключает отслеживание ранее добавленного YouTube-канала.

```text
!youtube on My Channel
!youtube off My Channel
```

## Управление AI-моделями

Команды этого раздела намеренно приведены в конце документа. Они работают только на сервере и доступны администраторам Discord или назначенным администраторам бота.

### `!model_list`

Показывает список доступных AI-моделей.

### `!model_add <имя>`

Добавляет модель в справочник AI-моделей.

```text
!model_add model-name
```

### `!model_remove <имя>`

Удаляет модель из справочника AI-моделей.

### `!model_set <chat|mini> <имя>`

Выбирает модель для текущего сервера:

- `chat` — основная модель для обычных AI-ответов и прожарки;
- `mini` — мини-модель.

Модель должна быть предварительно добавлена через `!model_add`. Тип `embedding` для этой команды не поддерживается: модель эмбеддингов не настраивается через `model_set`.

Пример:

```text
!model_set chat model-name
!model_set mini mini-model-name
```

## Управление AI-провайдерами

Команды этого раздела также находятся в конце документа. Они работают только на сервере и доступны администраторам Discord или назначенным администраторам бота.

### `!provider_list`

Показывает список доступных AI-провайдеров и их API URL. Токены в списке не отображаются.

### `!provider_add <имя> <url> <токен>`

Добавляет провайдера в справочник.

```text
!provider_add openai https://api.example.com/v1 TOKEN
```

Токен передаётся в содержимом Discord-сообщения. Используйте для этой команды только безопасный приватный канал и не публикуйте токен в общем чате.

### `!provider_remove <имя>`

Удаляет провайдера из справочника.

### `!provider_set <chat|embedding> <имя>`

Выбирает провайдера для текущего сервера:

- `chat` — основной AI-провайдер;
- `embedding` — провайдер для эмбеддингов.

Провайдер должен быть предварительно добавлен через `!provider_add`. Настройка провайдера эмбеддингов выполняется именно через `provider_set embedding`; команда `model_set embedding ...` отсутствует и не поддерживается.

Примеры:

```text
!provider_set chat openai
!provider_set embedding openai
```
